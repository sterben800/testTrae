# P5.js 分形图集合

这个项目包含两个经典的分形图形实现，使用P5.js库开发。

## 1. 科赫曲线 (fractal.html)

**科赫曲线**是一种经典的分形几何图形，由瑞典数学家Helge von Koch于1904年提出。

### 功能特性
- 绘制单条科赫曲线
- 绘制完整的科赫雪花（由三个科赫曲线组成）
- 鼠标点击可增加迭代次数（0-5次循环）

### 如何使用
1. 在浏览器中打开 `fractal.html` 文件
2. 观察科赫曲线和科赫雪花的生成
3. 点击画布可切换迭代次数，观察分形复杂度的变化

## 2. 曼德博集合 (mandelbrot.html)

**曼德博集合**是复平面上的一种分形集合，以数学家Benoît Mandelbrot命名，具有无限复杂的自相似结构。

### 功能特性
- 彩色曼德博集合可视化
- 鼠标点击缩放功能（点击位置为新的中心）
- 可调整迭代次数以获得更精细的细节
- 重置缩放功能

### 如何使用
1. 在浏览器中打开 `mandelbrot.html` 文件
2. 观察曼德博集合的复杂结构
3. 点击画布任意位置可放大该区域
4. 点击"重置缩放"按钮可恢复初始视图
5. 点击"增加迭代次数"按钮可提高渲染精度（100-500次循环）

## 技术说明

- 使用P5.js库进行图形绘制
- 采用递归算法实现科赫曲线
- 采用迭代算法实现曼德博集合
- 响应式设计，适配不同屏幕尺寸

## 浏览器兼容性

建议使用现代浏览器（Chrome、Firefox、Safari、Edge）运行，以获得最佳性能。
